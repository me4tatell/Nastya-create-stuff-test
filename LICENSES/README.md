# Шрифты и сторонние материалы

## Onest

В `index.html` встроен файл Onest (вариативный TrueType, без изменений).

Источник файла: https://github.com/google/fonts/tree/main/ofl/onest

Лицензия: SIL Open Font License 1.1. Полный текст, включая сведения об авторских правах, — в `Onest-OFL.txt`.

## CrazyV1

В `index.html` встроен CrazyV1 Regular, без изменений. Отображение прописными выполняет CSS и не изменяет файл шрифта.

Автор: Liam Butler.

Источник: https://fonts-online.ru/fonts/crazyv1

По сведениям страницы источника, шрифт распространяется по CC BY-SA 4.0. Полный текст этой лицензии — в `CrazyV1-CC-BY-SA-4.0.txt`, официальный адрес: https://creativecommons.org/licenses/by-sa/4.0/ . Атрибуция также сохранена в подвале сайта. Перед коммерческой публикацией рекомендуется подтвердить условия у правообладателя.

## Логотип и визуальные материалы

Логотип предоставлен владельцем проекта; для прототипа цвет изменён на #473528, прозрачность сохранена. Референсы не включены в папку публикации. Дудлы и карандашные рамки реализованы в коде; фотографии товаров пока заменены нейтральными заглушками.
